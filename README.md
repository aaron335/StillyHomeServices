# Stilly Home Services — Website

One-page marketing site for Stilly Home Services (interior & exterior painting, finish carpentry) serving Arlington, Stanwood, and greater Snohomish County, WA.

- **Live site:** _add your Vercel URL / domain here once deployed_
- **Stack:** single static `index.html` (no build step)
- **Hosting:** GitHub (source) → Vercel (auto-deploys on every push)

## Edit the site
Open `index.html` and edit the text/colors. Key spots:
- Replace `[YOUR PHONE]` (appears in the hero button, form note, and footer).
- Swap the `SH` logo box for your logo image.
- Replace the "Add photo" gallery slots with real job photos.
- Brand colors are the `--brand` and `--accent` values in the `<style>` block near the top.

## Deploy
Every push to the `main` branch auto-deploys to Vercel once the repo is connected. See `GitHub-Vercel-Deploy-Guide.md`.
